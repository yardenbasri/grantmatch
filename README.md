# GrantMatch

Matches Israeli SMEs to government grant programs.

## Stack

- Vite + React 18 + TypeScript
- MUI v5, RTL (`stylis-plugin-rtl`, emotion `CacheProvider`)
- Supabase (`@supabase/supabase-js`)

## Setup

```bash
npm install
npm run dev
```

Requires a `.env.local` with `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` (added in step 2).
